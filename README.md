# H&S BRIDGE — Sitio de presentación

Adaptación de la página Vanguard a la presentación de servicios facilitada por el usuario. Mantiene diseño azul/cian y animaciones.

Abre index.html en un navegador. Requiere conexión para Tailwind CSS, Google Fonts y Font Awesome. El logo se incluye localmente y procede del PDF.

Archivos: index.html, motion.css, motion.js y assets/logo.png.

Incluye las seis áreas de servicio, alcance desplegable, misión, ciclo de auditoría, capacitación, compromisos y datos de contacto del PDF. No incluye estadísticas ni testimonios inventados. Las referencias legales detalladas no se presentan como normativa vigente.

El formulario es demostrativo: valida campos pero no envía ni almacena información. Los enlaces de correo, WhatsApp y LinkedIn abren los canales de contacto publicados en la presentación; no envían mensajes automáticamente.

Para habilitar recepción de formularios se requiere una integración de correo o backend y definir el tratamiento de datos.

Páginas internas: organizacion.html y servicios.html. Publicar siempre toda la carpeta para conservar la navegación. El fondo se simplificó, sin órbitas ni partículas.
